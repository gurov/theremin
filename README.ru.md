# Air Theremin

**Играть: [theremin.bizibah.com](https://theremin.bizibah.com/)**

*[English version](./README.md)*

Браузерный терменвокс (аналог [theremin.site](https://theremin.site/)), в который играют **в воздухе** — двумя способами на выбор, переключатель `GYRO / HANDS` в панели:

**GYRO** — гироскоп телефона вместо курсора мыши:

- наклон **влево-вправо** → громкость;
- наклон **вперёд-назад** → высота тона.

Весь диапазон умещён внутри рамки на экране: вывел маркер за неё — звук пропал.

**HANDS** — трекинг обеих рук по камере (MediaPipe Hand Landmarker), режим «дирижёр»:

- **расстояние между ладонями** → громкость (развёл — громче, **ладони вместе = тишина**);
- **средняя высота обеих ладоней** → высота тона (поднял обе — выше);
- **угол наклона линии между ладонями** → глубина вибрато (покачал руками как качелями — нота запела; мёртвая зона не даёт вибрато включиться само);
- **расстояние до камеры** → тембр: ближе = ярче и суше, дальше = глуше и больше реверба.

Две ладони дают ровно три независимых числа — среднюю высоту, расстояние и угол между ними, — и маппинг выше это они и есть. Руки равноправны, ролей «левая/правая» нет. Рамки в этом режиме нет — границы задают сами руки. При первом за визит включении показывается анимированная подсказка из трёх шагов.

Трекинг рук целиком работает на вашей машине, **видео никуда не отправляется** — отправлять его, собственно, некуда, сервера у приложения нет. Модуль MediaPipe, его wasm и файл модели один раз тянутся с CDN; как положить их к себе — в разделе про хостинг.

Всё приложение — один самодостаточный файл [`index.html`](./index.html) на vanilla JS (Web Audio API + DeviceOrientation + MediaPipe). Сборка не нужна.

## Возможности

- Форма волны: sine / triangle / warm / reed (последние две — кастомные `PeriodicWave` с плавным спадом гармоник; raw saw/square убраны, на динамике телефона они трещали).
- Реверберация «пещера» (вкл/выкл, включена по умолчанию).
- Привязка к нотам — квантование в ближайший хроматический полутон (вкл/выкл).
- Эффекты: vibrato / tremolo / echo. В режиме HANDS тумблер вибрато заблокирован и работает как подпись — глубиной там правит наклон ладоней.
- Калибровка нуля под текущий хват телефона (в режиме HANDS не нужна и скрыта).
- Осциллограф и индикатор ноты/частоты. В режиме HANDS волна натянута между ладонями.
- Запись звука → скачивание файла (webm/opus или mp4 на iOS).
- Desktop-fallback: если гироскопа нет — управление мышью (для отладки на ПК).

Диапазон — **C2–C7**, пять октав. Динамик телефона физически не воспроизводит ничего ниже ~150 Гц, поэтому низ вытягивает не громкость, а психоакустический bass-exciter: нижняя октава насыщается, чтобы породить гармоники, а её основной тон после этого срезается фильтром — ухо достраивает высоту само. Бас читается как присутствующий и «в ноте» даже на крошечном динамике. Сатуратор питается голым осциллятором, а не сигналом после регулятора громкости, поэтому гармоники одинаковы на любой громкости; фильтр, убирающий основной тон, следует за нотой, а не стоит на фиксированной частоте.

## Важно: нужен HTTPS

И DeviceOrientation (гироскоп), и `getUserMedia` (камера) работают **только в secure context** — по `https://` или через `localhost`. На iOS 13+ гироскоп ещё и запрашивает разрешение по тапу (кнопка «START» это делает).

## Локальный запуск и тест на телефоне

1. Сгенерируй самоподписанный сертификат в папке проекта (подставь IP машины в LAN):

   ```bash
   IP=192.168.1.50   # ← свой IP (узнать: hostname -I / ip addr)
   openssl req -x509 -newkey rsa:2048 -nodes -days 365 \
     -keyout key.pem -out cert.pem -subj "/CN=$IP"
   ```

   Либо через [mkcert](https://github.com/FiloSottile/mkcert) (сертификат без предупреждений):
   ```bash
   mkcert -key-file key.pem -cert-file cert.pem 192.168.1.50 localhost
   ```

2. Запусти сервер:

   ```bash
   node serve-https.js
   ```
   Он напечатает адрес вида `https://192.168.1.50:8443`.

   > Альтернатива без файла сервера: `npx http-server -S -C cert.pem -K key.pem -p 8443`

3. Открой этот адрес на телефоне (тот же Wi-Fi), прими предупреждение о самоподписанном сертификате, нажми «START» и разреши доступ к движению (iOS).

Для отладки на ПК просто открой `https://localhost:8443` — включится управление мышью (или HANDS, если есть вебка).

## Хостинг на VPS

Приложение статическое — достаточно отдать `index.html` за настоящим TLS. Но обоим режимам нужны разрешения в заголовках, иначе браузер молча их заблокирует:

```
Permissions-Policy: gyroscope=(self), accelerometer=(self), camera=(self)
```

Режим HANDS вдобавок тянет ES-модуль и wasm с `cdn.jsdelivr.net` и модель с `storage.googleapis.com`. Если на сайте стоит строгий `Content-Security-Policy`, надо либо разрешить эти хосты (`script-src`/`connect-src`/`worker-src` + `'wasm-unsafe-eval'`), либо — предпочтительнее — сложить `vision_bundle.mjs`, `wasm/` и `hand_landmarker.task` рядом с `index.html` и заменить пути в `initCamera` на относительные.

**nginx:**
```nginx
server {
    listen 443 ssl;
    server_name theremin.example.com;
    ssl_certificate     /etc/letsencrypt/live/theremin.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/theremin.example.com/privkey.pem;
    root /var/www/theremin;   # сюда положить index.html
    index index.html;
    add_header Permissions-Policy "gyroscope=(self), accelerometer=(self), camera=(self)";
}
```
Сертификат — через `certbot`. С валидным TLS предупреждений на телефоне не будет.

**Caddy** (авто-TLS одной строкой в `Caddyfile`):
```
theremin.example.com {
    root * /var/www/theremin
    file_server
    header Permissions-Policy "gyroscope=(self), accelerometer=(self), camera=(self)"
}
```
